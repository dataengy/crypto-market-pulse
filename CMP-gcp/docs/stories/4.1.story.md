# Story 4.1: E2E integration + idempotent rerun

## Story
As the builder, I want one `just it` that proves FX on both paths and survives a full replay, so that the local lane has a single green/red signal (FR-10, SM-1).

## Boundaries
- **Always:** sequence `up → sql-apply → (shim & beam_run in background) → produce fixture → assert → produce fixture again → assert`; polling interval + timeout from config; stop only the background processes it started.
- **Never:** fixed sleeps; a separate assertion engine (`assert_fixture.py` compares against `reference.compute_stats`); leave orphan processes.

## Acceptance Criteria
1. **Given** a clean emulator state, **when** `just it` runs, **then** `trades_1m` **and** `trades_1m_beam` BTCUSDT 10:00 = FX, and the ETHUSDT and BTCUSDT 10:01 buckets match the oracle.
2. **Given** a second fixture replay, **then** raw trade rows double (8 → 16) and both bars are unchanged.
3. **Given** a timeout, **then** the failure names the path (`sql`/`beam`) and the last observed row.
