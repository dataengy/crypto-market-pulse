# Story 1.1: Runtime discovery & reuse

## Story
As the builder, I want a read-only inventory of local tools and containers, so that I reuse what exists before creating anything (UJ-1, FR-1).

## Boundaries
- **Always:** read-only commands only; per-command `docker --context`, never `docker context use`; the inventory goes to `.tmp/` (gitignored), never committed.
- **Never:** install, start, stop or pull anything; dump env vars or secret files; build a generic multi-service discovery framework (only GCP-lane deps: gcloud + pubsub-emulator, Java 17, bq, duckdb, uv, just, docker/colima, port listeners).

## Acceptance Criteria
1. **Given** Docker/Colima is absent, **when** `just discover` runs, **then** it exits 0 and marks those rows `absent`.
2. **Given** a Pub/Sub emulator already answers on the configured host:port, **when** discover runs, **then** the selected option is `reuse` with reason.
3. **Given** any run, **then** no files change outside `.tmp/` and no container state changes (`docker ps -a` identical before and after).
