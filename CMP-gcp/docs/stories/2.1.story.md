# Story 2.1: Local emulators (Pub/Sub + BigQuery)

## Story
As the builder, I want an idempotent `just up/down` that reuses a running Pub/Sub emulator and adds only what is missing, so that the loop starts the same way every time without touching shared services (FR-4, AD-7).

## Boundaries
- **Always:** endpoint priority = healthy existing → host `gcloud beta emulators pubsub start --project=<cfg> --host-port=127.0.0.1:<cfg>` → compose. BigQuery = compose `ghcr.io/goccy/bigquery-emulator` (pinned tag). `docker compose -p cmp-gcp up -d --wait`; binds `127.0.0.1`; label `com.crypto_market_pulse.owner`; healthchecks. Write `PUBSUB_EMULATOR_HOST` and `BIGQUERY_EMULATOR_HOST` to `.tmp/emulators.env`. Re-create topic/subs idempotently (emulator state is memory-only).
- **Never:** `down -v`, `rm -f`, prune, `docker context use`; start a stopped container someone else owns; a custom wrapper around compose beyond the justfile.

## Acceptance Criteria
1. **Given** nothing is running, **when** `just up` runs twice, **then** there is exactly one container per service and `docker compose -p cmp-gcp ps` shows them healthy.
2. **Given** an externally started emulator on the configured port, **when** `just up` then `just down`, **then** that emulator is still running (no-op for reused services).
3. **Given** `just up`, **then** topic + subscriptions `shim` and `beam` exist (names from config), and a second `up` raises no AlreadyExists error.

## Tasks / Subtasks
- [ ] `compose.yml`: `cmp-gcp-bq` (always) + `cmp-gcp-pubsub` (profile `fallback`, `google-cloud-cli:emulators` pinned).
- [ ] `scripts/emulators.py` (or `just` + `curl`, whichever is shorter): probe the endpoint → choose → write `.tmp/emulators.env` → ensure topic/subs.
- [ ] `tests/it/test_emulators.py::test_up_twice_idempotent` (marker `needs_emulators`).
- [ ] `justfile`: `up`, `down` (stop only the project's own services).

## Verification
`just up && just up && docker compose -p cmp-gcp ps --format json | jq length` → the expected count; `curl -s $PUBSUB_EMULATOR_HOST/v1/projects/<p>/topics` lists the topic. Docker needs the already-approved sandbox bypass.
