# Story 4.3: Live Bybit smoke (local)

## Story
As the builder, I want a bounded live run into the emulators, so that real-world shape (rate, reconnects, lag) is seen before any cloud work (FR-12).

## Boundaries
- **Always:** `produce --source bybit --max-seconds <cfg>`; endpoint, ping and backoff from config; record `max_ingest_lag_ms` in evidence.
- **Never:** backfill gaps; run unbounded; any credentials (the public stream needs none).

## Acceptance Criteria
1. **Given** network access to the Bybit public WS, **when** the smoke runs, **then** both `trades_1m` and `trades_1m_beam` have rows for the current minutes.
2. **Given** a network toggle mid-run (scratch session), **then** a reconnect is logged and the gap is written into evidence.
