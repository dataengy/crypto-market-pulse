# Story 4.4: Hermetic CI

## Story
As the repo owner, I want PRs touching `CMP-gcp/**` to run unit + TestStream + emulator integration tests with no cloud credentials, so that regressions are caught before merge (FR-13).

## Boundaries
- **Always:** GitHub Actions at the repo root `.github/workflows/cmp-gcp.yml` with `paths: [CMP-gcp/**]`, excluding `CMP-gcp/deploy/**` (cloud lane owns its own CI); service containers use the same pinned images as `compose.yml`; the hardcoded-scalars check runs too.
- **Never:** `google-github-actions/auth`, WIF, secrets, or cloud smoke (that is [GCP-C09](../../../docs/plans/gcp/tasks.md#gcp-c09)); push or open a PR without user confirmation; touch other lanes' workflows.

## Acceptance Criteria
1. **Given** a PR changing `CMP-gcp/` (outside `deploy/`), **then** jobs `unit`, `beam` and `it` (`needs_emulators`) run and pass.
2. **Given** the workflow file, **then** it contains no `secrets.` reference.

## Tasks / Subtasks
- [ ] `.github/workflows/cmp-gcp.yml` (Pub/Sub emulator via the `google-cloud-cli:emulators` image; goccy as a service).
- [ ] Local dry check: `actionlint` if already installed (discover first, don't install).

## Verification
`grep -c 'secrets\.' .github/workflows/cmp-gcp.yml` → `0`; a green run on a PR (after the user confirms push).
