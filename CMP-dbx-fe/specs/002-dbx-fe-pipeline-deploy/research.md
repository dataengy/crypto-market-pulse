# Research: Free Edition deploy

| Topic | Finding / decision | Status |
|---|---|---|
| Free Edition limits | Serverless only; 1 active pipeline per type; 1 × 2X-Small warehouse; Apps ≤ 3 with 24 h runtime; egress to trusted domains only ([docs](https://docs.databricks.com/aws/en/getting-started/free-edition-limitations)) | checked 2026-10-30 |
| Kafka egress | Unknown, so the probe job [DBX-C02](../../../docs/plans/dbx-fe/tasks.md#dbx-c02) is a gate before any pipeline work | **unverified** |
| Kafka provider | Confluent Cloud SASL_SSL/PLAIN by default; any SASL/PLAIN Kafka works by config. The comparison is in [DBX-B5](../../docs/backlog/kafka-provider-choice.md) | open |
| Login module | Databricks ships a shaded client, so `kafkashaded.org.apache.kafka…PlainLoginModule` is set in `config.yaml` | per Databricks Kafka docs; unverified on Free Edition |
| Pipeline Python deps | `environment.dependencies: [pyyaml]` on a serverless pipeline | **unverified**: `bundle validate` will tell |
| Dashboard | `.lvdash.json` generated by `build.py`; `dataset_catalog` / `dataset_schema` set by the bundle | **unverified** |
| Query from the CLI | `databricks experimental aitools tools query` (`just dbx-query`) | **unverified**; the fallback is the SQL editor in the UI |
